# Roadmap

Work planned for worksheet-app, roughly in order. Shipped so far: maze, word search and cutting
worksheets (AI-generated subject or uploaded photo), deployed to Cloudflare Pages and Render.

## Fix known issues

- **UI polish**: the form is plain and unpolished.
- **Layout**: fix the remaining layout issues.
- **Maze rendering**: improve the quality of the rendered maze.
- **Error details in the browser**: when generation fails the API returns a `details` field, but
  the form shows only the generic `error` message.

## Storage

- **Cloudflare R2**: upload generated icons and PDFs on generation, through the S3 SDK
  (`services/storage.ts` is still to be written).
- **Persistent icon cache in Cloudflare KV**: the icon cache is in memory today, so it is lost on
  every restart, and Render's free tier restarts the API after each idle spell.
- **R2 public bucket as an asset CDN**.

## New activity types

- **Counting**, **tracing** and **matching**: the shared types and dropdown entries exist (hidden in
  production builds); the generators and PDF layouts don't.

## Social story generator

Short stories that walk a child through an everyday situation, generated by an LLM, with a
guardrail layer that screens the generated text before it goes on the page.

## Worksheet history

Re-download earlier worksheets, plus basic usage analytics, backed by Cloudflare D1 or Turso.
